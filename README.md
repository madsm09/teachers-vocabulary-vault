# Vocab Vault — Instructor Hub
A classroom word-games hub for linguistics, literature and social-science vocabulary. Plain HTML/CSS/JS, hosted on Netlify.

Run locally: `netlify dev --port 8889` (or any static server on `public/`).

Roadmap: see PLAN.md — remaining word banks (Phonology & Morphology, Sociology) and the playable games (riddles, crossword, Pictionary, word search, hangman, scramble, quiz, red-string match, memory, flashcards, timed sprint).
